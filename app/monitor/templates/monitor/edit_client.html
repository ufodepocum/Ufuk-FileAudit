Bağlantı ve kurulum adımları

Yönetici hesabı yalnızca bu işlem için kullanılır; parola sunucuda veya veritabanında saklanmaz. Ajan Windows SYSTEM hesabıyla çalışır. Mevcut ajan güncellenirken kısa süreli yakalama kesintisi oluşur.

{% csrf_token %}

Proxy veya DNS kullanıyorsanız Windows sunucusunun erişebildiği adresi yazın.

1. Paylaşımları bul

Windows üzerindeki gerçek SMB paylaşımları ve yerel disk yolları okunur. Sadece IP yazmak hangi klasörlerin izleneceğini belirlemez.

İzlenecek paylaşımlar (alt klasörleriyle birlikte)

2. Npcap kontrolü

Eksikse imzalı Npcap yükleyicisi Windows'a indirilir. RDP ile grafik kurulumu tamamlayıp aynı düğmeyle yeniden kontrol edin.

3. Windows bileşenlerini hazırla

Python ve Wireshark hazırlanır. Bu işlem internet hızına göre birkaç dakika sürebilir; işlem bitene kadar sayfayı açık tutun.

4. Seçimi uygula ve doğrula

Seçim boş bırakılamaz. API erişimi, Npcap ve paket yakalama doğrulanır; doğrulama başarısızsa önceki ajan ayarları geri alınır.

Önce sunucuya bağlanıp paylaşımları bulun.
